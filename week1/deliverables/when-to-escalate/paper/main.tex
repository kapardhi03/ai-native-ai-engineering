\noindent\textbf{Problem statement.}
The agent observes an inbound message from a sales lead. It must
select one action from \{answer, ask a qualifying question, hold,
escalate\_notify, escalate\_pause\} because the lead's true intent and
buying-readiness are not known. Here \emph{escalate\_notify} alerts a human
while the conversation continues and \emph{escalate\_pause} stops the agent and
hands over; the two are separate actions because they carry different costs.
